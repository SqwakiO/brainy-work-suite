# AI Workplace Productivity Assistant

A modern, responsive SaaS-style web app that helps professionals automate everyday workplace tasks with AI.

## Features

- **Smart Email Generator** — draft professional emails from a short brief, tone and audience aware.
- **Meeting Notes Summarizer** — turn raw notes or transcripts into summaries, decisions and action items.
- **AI Task Planner** — break goals into prioritized, scheduled task lists.
- **AI Research Assistant** — structured briefings on any topic with clear sections.
- **AI Chatbot Interface** — a general-purpose workplace copilot for follow-up questions.

Every tool uses structured prompts, returns **editable output** you can refine before use, and shows a **responsible AI disclaimer** reminding you to verify important information.

## UI

- Modern dashboard with sidebar navigation
- Fully responsive (mobile drawer navigation, desktop sidebar)
- Clean, professional design system with semantic theme tokens

## Tech Stack

- **TanStack Start** (React 19, file-based routing, server functions)
- **Vite 7** build tooling
- **TypeScript**
- **Tailwind CSS v4** + shadcn/ui components
- **Lovable AI Gateway** via the Vercel AI SDK for model access

## Project Structure

```
src/
  components/     AppShell, ToolWorkspace, AiDisclaimer, UI primitives
  lib/            AI server functions and gateway provider
  routes/         index (dashboard), email, notes, planner, research, chat
  styles.css      Tailwind v4 theme tokens
```

## Development

Requires Node.js and npm.

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```

The dev server runs at `http://localhost:8080`.

### Environment

AI requests are served through the Lovable AI Gateway and require `LOVABLE_API_KEY`
in the server environment. It is provisioned automatically in Lovable.

## Deployment

Open the project in [Lovable](https://lovable.dev) and click **Publish**. The app can
also be self-hosted anywhere that supports a TanStack Start edge deployment.

## Responsible AI

Outputs are generated by a language model and may be inaccurate. Always review
AI-generated content before sending, sharing, or acting on it.
